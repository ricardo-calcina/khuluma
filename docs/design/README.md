# Design concepts

Painter concepts from the 2026-10-30 menu and window workshop. They are
references for direction, not specifications; `DESIGN.md` describes what was
built.

- `menu-concepts.png`: A (current menu plus the Auto-send switch), B (Today
  strip) and C (Ready line). Chosen: B's 7-day bars and A's footer, without
  the All time caption or the last-dictation line. The figures cover All time
  or Today (Settings → Appearance → Menu figures), and the bars can be hidden.
- `window-concepts.png`: 1 (sidebar) and 2 (toolbar tabs). Chosen: 2, with
  Stats | Vocabulary | Settings tabs so the window keeps its width for
  content. Vocabulary moved from a sheet to a tab.
